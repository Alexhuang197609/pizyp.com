# 派之优品 PiZhiYouPin (pizyp.com)
---
## 📌 Project Introduction 项目介绍
This is a full-featured open-source e-commerce mall built for the Pi Network ecosystem, developed using Rust + Axum + SQLite. It supports product display, shopping cart, order management, Pi payment authorization, personal center and other complete mall functions, deployed on the Pi Network Testnet.
这是面向 Pi Network 生态开发的全功能开源电商商城，采用 Rust + Axum + SQLite 技术栈开发，支持商品展示、购物车、订单管理、派支付授权、个人中心等完整商城功能，部署于 Pi Network 测试网。
---
## 🛠 Tech Stack 技术栈
- Backend: Rust, Axum, SQLx
- Database: SQLite
- Frontend: Native HTML/CSS/JS
- Blockchain: Pi Network SDK (Testnet)
---
## ✨ Core Features 核心功能
- Complete product category & commodity display 完整商品分类、商品展示
- Shopping cart & one-click purchase 购物车、立即购买下单
- Pi Network official payment authorization 派官方 SDK 支付授权
- Order management (pending payment / completed) 订单管理
- Personal center & user information management 个人中心、用户信息管理
