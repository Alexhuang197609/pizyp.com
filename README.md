# pizyp.com派之优品
## 📌 Project Introduction 项目介绍
This is a full‑featured open‑source e‑commerce mall built for the Pi Network ecosystem, developed using **Rust + Axum + SQLite**.
Supports product display, shopping cart, order management, Pi payment authorization, personal center and other complete mall functions, deployed on Pi Network Testnet.
这是面向Pi Network生态开发的**全功能开源电商商城**，采用 Rust + Axum + SQLite 技术栈开发。
支持商品展示、购物车、订单管理、派支付授权、个人中心等完整商城功能，部署于Pi Network测试网。

## 🛠 Tech Stack 技术栈
- Backend: Rust, Axum, SQLx
- Database: SQLite
- Frontend: Native HTML/CSS/JS
- Blockchain: Pi Network SDK (Testnet)

## ✨ Core Features 核心功能
1. Complete product category & commodity display 完整商品分类、商品展示
2. Shopping cart & one‑click purchase 购物车、立即购买下单
3. Pi Network official payment authorization 派官方SDK支付授权
4. Order management (pending payment / completed) 订单管理
5. Personal center & user information management 个人中心、用户信息管理
